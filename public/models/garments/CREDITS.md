# Baked garments (male.glb, female.glb)

Made in-house for Skyrome by cloth simulation (Blender 5.1's cloth solver) in `tools/characters/garments.py`: the
garment patterns, pins and drape are generated by that script; no third-party garment model or texture is used.
Licence: CC0 1.0 Universal, like the rest of the generated assets.

The collision body the cloth was simulated on is the game's own reference body (`public/models/people/<sex>.glb`),
which is derived from Blender Studio's **Human Base Meshes** (CC0 1.0, see `public/models/people/CREDITS.md`). The body
is not part of these files.

Rebuild: `node tools/characters/garments.mjs [male|female] [--only=toga,stola]` (see docs/modules/avatar-real.md,
"Baked cloth").
