# Credits: city fabric, props, vegetation

No third-party assets are used. All geometry (buildings, streets, props and plants), the wind shaders and the noise functions are original procedural code in `src/arch/fabric`, `src/arch/props` and `src/arch/vegetation`.

The only external code is three.js (MIT), through its `BufferGeometryUtils` (`mergeGeometries`, `mergeVertices`), which was already a project dependency.
