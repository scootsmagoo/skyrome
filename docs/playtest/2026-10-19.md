Either the trip counter and the unstick logger count different things, or the logger is not recording. Log lines: `minute 15: ... trips 59 (stuck 17)` and `NPC unsticks: 0 total (0 logged, 0.0 per minute)`. Not a gameplay bug by itself. It means the stuck signal from this run is not trustworthy.
2. **Deaths recovered as designed.** Three deaths (`[soak] player died at 28,8,1`, `19,8,22`, `113,8,14`), each rescued (1, 2, 3 so far). No failures.
3. **FPS.** Held at 58–60 for most minutes. The one dip is minute 15 at 52 fps, which is above the 30 fps threshold. No dips below 30.
4. **No errors.** `grep -i 'error|warn|uncaught|stuck'` found only the stuck counters above and the `errors 0` in the verdict. No page errors, no uncaught exceptions.
