2. **NPC unsticks: 0.** `NPC unsticks: 0 total (0 logged, 0.0 per minute)`, and `/tmp/stuck-2026-11-07.json` contains `total: 0`. The NPC stuck system did not trigger during this run.
3. **Fps dips:** lowest samples were 44 fps (minute 5, the minute of the first death) and 52 fps (minute 14). Nothing fell below 30 fps.
4. **Death recovery:** 3 deaths, 3 recovered. Log: `[soak] player died at -19,8,-1; rescued (1 so far)`, `... at -29,10,6; rescued (2 so far)`, `... at 40,8,65; rescued (3 so far)`.
5. **Environment noise, not a game error:** the log contains 2124 lines `file watcher error: ENOSPC: System limit for number of file watchers reached` (Vite's dev-server watcher). This is the host's inotify limit, not a page error. The soak's error count is 0. Fixing it needs a host-level `fs.inotify.max_user_watches` increase, which is a sysadmin action.
