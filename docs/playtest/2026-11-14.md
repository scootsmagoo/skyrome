1. **Stuck counter vs NPC unstick log disagree.** The per-minute "stuck" counter reached 8 by minute 15, but the NPC unstick report printed "0 total (0 logged)" and `/tmp/stuck-2026-11-14.json` contains `total: 0`. This is the same mismatch seen in 2026-10-14. The two counters measure different things, so it may not be a bug, but it is still unexplained. Log: the "NPC unsticks: 0 total" line and the final minute 15 line.
2. **FPS dipped below 30 twice** (minute 2: 24 fps; minute 13: 29 fps). The cause was not investigated, and the run did not record a profile. Log: minute 2 and minute 13 lines.
3. **Vite file-watcher errors at boot.** The dev server logged many `file watcher error: ENOSPC: System limit for number of file watchers reached` lines (about 2,100 lines in the log). The soak still ran to completion and the verdict is PASS, so this looks like host environment noise rather than a game bug. It is the first lines of the log.
4. **Deaths: 3, all recovered.** Rescues logged at minutes 5, 9 and 14. No unrecovered deaths.

Errors: `grep -i error|warn|uncaught` on the log, excluding the ENOSPC watcher lines, returned no matches. Page errors: 0. Crashed: false.
