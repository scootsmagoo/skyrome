## Findings

1. **Frame rate dipped below 30 fps at two minute samples.** Minute 3 read 24 fps (log line 2128) and minute 10 read 26 fps (log line 2137). The soak samples once per minute, so these are point readings, not minimums. Whether they are a real hitch or a bot-side effect of a fight or load is not established by this run. Needs a look with `scripts/perf.mjs` or the `?debug` overlay.
2. **Bot stuck trips rose from 1 to 6.** This counts bot trips where the goal was not reached for more than 40 ticks (soak.mjs line 148). It is not the NPC unstick count, which was **0** (log: "NPC unsticks: 0 total"). The stuck JSON written to `/tmp/stuck-2026-11-11.json` is consistent with that (total 0). Cause not investigated.
3. **Deaths: 3, all recovered by the Aesculapian rescue.** Log lines 2130, 2136 and 2142 (at 71,8,4; 45,11,-56; 9,8,-7). No unrecovered death.
4. **Environment noise, not a game error.** 2124 lines of `file watcher error: ENOSPC: System limit for number of file watchers reached` (log lines 1–2124) came from the Vite dev server started by the soak. The host's inotify instance limit is 128 (`max_user_instances`). Cause of exhaustion not verified. The soak ran regardless. Host fix, not a game fix: raise `fs.inotify.max_user_instances` or stop idle dev servers.

No `Uncaught`, `error` or `warn` lines came from the game. Grep for those returned only the watcher lines above.
