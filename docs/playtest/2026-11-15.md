## Findings

1. **Stuck counter disagrees with the stuck file.** The log's per-minute `stuck` counter rises from 2 to 8. The file `/tmp/stuck-2026-11-15.json` contains `"total": 0` and an empty `log`. Either the file is not written from the same counter, or it is written only on some paths. Unverified which. Not a game bug as far as this run shows. Needs a look at how `soak.mjs` writes `--stuck`.
2. **Deaths were all recovered.** Three deaths at about minutes 5, 10 and 15 (log lines 6, 12, 18). Each was followed by `rescued`, and the counter matched.
3. **Frame rate dipped to 34 fps at minute 7 and 43 fps at minute 11.** Neither dropped below 30 in the per-minute samples. The samples are one reading per minute, so shorter dips are not visible here.
