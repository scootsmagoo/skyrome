## Findings

1. **No page errors, no crash, no Uncaught exceptions.** `grep -i 'error|warn|uncaught'` finds only the watcher lines below and the soak's own `errors 0` summary (log line 2121).
2. **Vite file-watcher limit hit (environment, not game code).** About 2,095 lines of `file watcher error: ENOSPC: System limit for number of file watchers reached` (log lines 1 to 2095) came from the dev server that `soak.mjs` starts. It means the host's inotify watch limit is used up, so Vite cannot watch files. It did not stop the run, but it can cause hot-reload problems and may hide real errors in noisy logs. The fix belongs on the host (raise `fs.inotify.max_user_watches` or stop other watchers). Not a game finding.
3. **Stuck counters vs NPC unstick log (the same mismatch as 2026-10-14).** The per-minute `stuck` count reached 5 by minute 12, but the NPC unstick report says `0 total` (log line 2115), and `/tmp/stuck-2026-11-10.json` has `total: 0`. The two counters measure different things, so this may not be a bug. It is still unresolved, and the stuck JSON gives no evidence of NPC stuck events in this run.
4. **Deaths: 3, all recovered.** Rescues logged at log lines 2101, 2107 and 2113. No unrecovered deaths.
5. **Frame rate.** Lowest sample was 46 fps (minute 3), with no dips below 30. Unlike 2026-10-14, the samples did not freeze, and positions changed every minute.
