## Findings

1. **Deaths and recovery (informational).** The player died three times (minutes 4–5 at 67,8,33; minutes 9–10 at -5,8,-9; minute 14 at 10,8,-7). Each was rescued by the Aesculapian rescue path. The log line is `[soak] player died ... rescued (N so far)`.
2. **FPS dip (below target, above 30).** Minute 5 averaged 45 fps. The other minutes ran 56–60 fps. No minute went below 30.
3. **Stuck counter rose during the run, not reconciled.** The per-minute counter `stuck` climbed from 3 to 15. The stuck log file `/tmp/stuck-2026-11-06.json` reports `total: 0` with an empty log, and the soak summary reports `NPC unsticks: 0 total`. The two sources disagree. The counter may count bot-side stalls rather than NPC unsticks, but this run does not show which. Worth checking the soak script's counter definition.
4. **File-watcher ENOSPC noise (environment, not game).** The log opens with about 2,124 lines of `file watcher error: ENOSPC: System limit for number of file watchers reached`. These come from the host's inotify limit (the Vite dev server watching the repo and docs), not from the game. They do not affect the verdict. Raising `fs.inotify.max_user_watches` on the host would silence them.
5. **Errors and warnings.** `grep` for `Uncaught`, `pageerror`, `console.error`, `TypeError` and `ReferenceError` found nothing. The soak reports `errors 0`.
